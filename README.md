# Кочевник. Планирование

Модуль для планирования любой деятельности: производства, торговли,  составления учебных планов и путешествий.

Во входном файле [task.md](task.md) можно посмотреть формат данных и комментарии.

На выходе получаете HTML файл с ленточным графиком, который можно посмотреть в браузере.

---
### Запуск
**java -jar [gen_aps.jar](gen_aps.jar) task.md**

или

**java -jar [mcts_aps.jar](mcts_aps.jar) task.md**
